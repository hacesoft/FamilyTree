# FamilyTree 1.1.6 – App Store screenshots

The Nextcloud app icon is the owner-approved `src/img/app.svg`, installed as `img/app.svg`. Its bytes are unchanged.

The three owner-approved screenshots are **external repository assets**. Upload the original PNG files manually to the `screenshot/` folder at the **root of the public GitHub repository** `hacesoft/familytree`, branch `main`:

- https://raw.githubusercontent.com/hacesoft/familytree/main/screenshot/01.png
- https://raw.githubusercontent.com/hacesoft/familytree/main/screenshot/02.png
- https://raw.githubusercontent.com/hacesoft/familytree/main/screenshot/03.png

No screenshots are included in the Publisher input archive, public full-source ZIP or signed runtime TAR.GZ. They are not modified, recompressed or generated by the release tooling. The signed archive retains the mandatory app SVG icon. README files reference the external `screenshot/01.png`, which renders in the GitHub repository after uploading it; the downloaded source ZIP does not include the PNG.

**Release gate:** publish the images first, then execute `node scripts/check-appstore-public-urls.cjs` from a machine with internet access. It must verify HTTP 200, PNG data, dimensions, size and SHA-256 as recorded in `scripts/appstore-approved-assets.json`. Do not publish a signed App Store release while this verification is pending or failing. After publication, verify the app card and image proxy gallery separately.
