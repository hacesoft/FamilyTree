# Import a export výzkumného deníku (JSON v1)

Import: **Rodokmen → ⋯ u konkrétního stromu → Výzkumný deník → Importovat výzkumný deník (JSON) → Zkontrolovat → Importovat**.

Export: stejná karta → **Exportovat výzkumný deník (JSON)**. Pro archivaci všech osob, vztahů, médií, návrhů a historie je nutná **úplná záloha ZIP v2**.

Formát, přesná struktura JSONu, limity, způsoby deduplikace, import do stejného/jiného stromu a bezpečnostní pravidla jsou v [FORMATY_IMPORT_EXPORT.md](FORMATY_IMPORT_EXPORT.md).

**Při externím genealogickém výzkumu** lze připravit strojově importovatelný JSON a samostatnou čitelnou zprávu Markdown. Dodržujte strukturu v [FORMATY_IMPORT_EXPORT.md](FORMATY_IMPORT_EXPORT.md). Kandidátní matrika není ověřený sňatek; `no_result` lze použít jen po skutečném procházení skenů. Starší výzkumná tvrzení nepřevádějte bez kontroly 1:1 na nové deníkové úkoly.
